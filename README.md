# Üst Menü Kaldırma Düzeltmesi

Bu paket yalnızca GitHub iframe sayfalarının üstündeki tekrar eden:

- Ne Kadar Yakar?
- Ayrıntılı
- Karşılaştır
- Aylık

menüsünü kaldırır.

## Yüklenecek dosyalar

Mevcut `nky-hesaplama-araclari` reposunda aşağıdaki dosyaları yenileriyle değiştirin:

- `ayrintili-hesaplama/index.html`
- `arac-karsilastirma/index.html`
- `aylik-hesaplama/index.html`

Blogger sayfalarında veya Blogger temasında bu düzeltme için değişiklik yapmayın.

Commit sonrasında GitHub Pages dağıtımının tamamlanmasını bekleyin ve sayfayı Ctrl+F5 ile yenileyin.
